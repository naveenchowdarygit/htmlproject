FEDF-PS38: Web-Based Platform for Educational Webinars and Workshops

📘 Project Overview

The EduWebinars Platform is a comprehensive web-based system that enables students to explore, register for, and engage in various educational webinars and workshops. It aims to bridge the gap between learners and educators through a simple, accessible, and interactive digital platform.

The system provides a dashboard for tracking registered events, upcoming sessions, and messages sent via contact forms — all powered by HTML, CSS, and JavaScript-based features.

💻 Technologies Used

  • HTML — for the overall structure and content organization of the platform.
  • CSS — for styling, color coordination, and responsive page design.
  • JavaScript — for form validation, interactivity, and dashboard data management using localStorage.
